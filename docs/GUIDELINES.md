# Cyber Hygiene Guidelines 2026

1. **Multi-Factor Authentication (MFA)**: Always enable hardware or authenticator app MFA.
2. **Password Entropy**: Use minimum 16-character passphrases.
3. **Phishing Recognition**: Verify sender domains and header signatures.
4. **Credential Segregation**: Never mix development tokens with production repositories.
